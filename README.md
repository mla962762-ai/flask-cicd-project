# Flask CI/CD Project 🚀

A simple Flask web application demonstrating CI/CD pipeline using Jenkins and Docker.

## 📋 Project Overview

This project implements a complete CI/CD pipeline with:
- **Build**: Docker image creation
- **Test**: Automated testing with pytest
- **Deploy**: Container deployment on Docker Desktop

## 🛠️ Technologies Used

- **Python 3.11** - Application runtime
- **Flask** - Web framework
- **Docker** - Containerization
- **Jenkins** - CI/CD automation
- **Pytest** - Testing framework
